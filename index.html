A QUICK FIELD GUIDE

How Articulator works

01

Set a semantic compass

In Workbench, enter a Toward (A) and Away from (B) concept. Add parallel pairs to average several examples, or switch between contrast, shared-ground, and midpoint lenses.

02

Follow sourced word paths

Open English WordNet returns sense-level definitions and lexical relations; Datamuse adds meaning-like words and text associations, labeled as such on Workbench cards. The original Studio map also uses Datamuse (WordNet-style, not a strict WordNet lookup). Workbench lookups run on Explore; Studio lookups run on Generate or Refresh.

03

Read model scores as rankings

The optional MiniLM model embeds and ranks candidates in your browser. Scores are alignment—not probabilities, facts, or causal claims. Add a context hint when a word has multiple senses.

04

Branch or draft

Set a result as a new A, copy an evidence note to the Studio, or explicitly ask for AI wildcards. Wildcards are unverified; that action sends the concepts and context hint to the hosted model. In Studio, “Expand this idea” separately sends your seed and selected links.

Clear sources, clear boundaries. No AI runs automatically. Workbench wildcards send the concepts and context hint only after you ask; Studio expansion sends its seed and selected meaning links only after you choose Expand. Saved Studio ideas stay in this browser.
